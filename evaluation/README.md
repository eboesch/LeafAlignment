## Folder Overview

This folder contains all notebooks and scripts used for evaluation and visualization of results


- `evaluation.py` :  Script used for running preliminary individual registration experiments
- `Final_Eval.ipynb` :  Notebook used for analysis of final experiment results and generating plots 
- `Registratoin_Eval.ipynb` :  Notebook used for analysis and evaluation of preliminary individual registration experiments
- `Robustness.ipynb` :  testing robustness of LoFTR 
- `Robustness_Vis.ipynb` :  Evaluating and visualizing LoFTR robustness results 
- `Series_Registration_Eval_Vis.ipynb` :  Notebook used analysis and evaluation of preliminary series registration experiments
- `Series_Registration_Evaluation.ipynb` :  Notebook used for running primary evaluation of sequence registration 
- `test_set.txt` :  list of leaf uids comprising our test set
